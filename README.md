# WaveNest

A decentralized music discovery platform with AI-generated recommendations built on the Stacks blockchain.

## Features
- Artist profile registration and management
- Song/Album NFT minting with royalty splits
- Collaborative song creation with customizable revenue sharing
- Playlist creation and management for listeners
- Listener profile and preferences tracking
- AI-powered music recommendations
- Token-based rewards system for active users

## Contract Functions
- Artist registration and profile management
- Song/Album NFT minting with collaborator splits
- Playlist creation and song management
- Listener interaction tracking
- Automated royalty distribution
- Recommendation engine integration
- Token rewards distribution

## Smart Contract Features
### Royalty Splits
- Support for up to 5 collaborators per song
- Customizable revenue sharing percentages
- Automatic royalty distribution on plays
- Transparent earnings tracking

### Playlist Management
- Create up to 20 playlists per listener
- Add/remove songs from playlists
- Track playlist popularity
- Share playlists with other users

## Getting Started
1. Clone the repository
2. Install dependencies
3. Run tests using Clarinet
4. Deploy contract to testnet/mainnet

## Testing
```bash
clarinet test
```
